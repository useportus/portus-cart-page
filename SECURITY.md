# Security Policy

If you believe you have found a security issue in Portus Cart Page, please do not open a public issue.

Email the maintainer at plugins@useportus.com with:

- a short description of the issue;
- steps to reproduce;
- affected version;
- WordPress, WooCommerce, and PHP versions;
- any relevant screenshots or logs with credentials and personal data removed.

Do not include passwords, license keys, payment details, or customer/order data in a public report.

We will review the report and respond as soon as possible.
